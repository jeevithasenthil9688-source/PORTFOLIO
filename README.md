## 🎨 How to Edit Content Later (Without Breaking Anything)

### 1. Changing Text or Adding New Information
- Right-click `index.html` and choose **Open with > Notepad** (or VS Code).
- Press `Ctrl + F` to search for the words you want to change (e.g., search `8.68` to update your CGPA, or search `Projects` to add a new project).
- Edit the text between the tags, and save the file (`Ctrl + S`).
- Refresh your browser tab to see your changes instantly!

### 2. Updating Your Photo or Resume
- To change your picture: Save your new photo as `photo.jpg` and replace the file in the `assets/` folder.
- To update your resume: Save your new resume PDF as `resume.pdf` and replace the file in the `assets/` folder.

### 3. Adjusting Theme Colors
- Open `style.css` in Notepad or VS Code.
- At the very top (lines 10–30), look for `:root`.
- You can change `--accent-cyan: #00f0ff;` to any color code you like (e.g., emerald green `#10b981` or royal purple `#a855f7`).

## 🌐 How to Host & Publish for Free

### Option A: Netlify Drop (Easiest — Takes 1 minute!)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop) in your browser.
2. Sign up or log in for free.
3. Drag and drop the whole `jeevitha-portfolio` folder into the upload circle on the webpage.
4. Netlify will publish your site in 5 seconds and give you a free link (e.g., `https://jeevitha-portfolio.netlify.app`) that you can share with recruiters!

### Option B: GitHub Pages
1. Go to [github.com](https://github.com) and log into your account (`jeevithasenthil9688-source`).
2. Click **New Repository**, name it `portfolio` (or `jeevithasenthil9688-source.github.io`).
3. Set the repository to **Public**.
4. Upload all files (`index.html`, `style.css`, `script.js`, and the `assets` folder).
5. Go to **Settings > Pages** in your GitHub repository.
6. Under **Branch**, select `main` and `/root`, then click **Save**.
7. Your portfolio will be live at `https://jeevithasenthil9688-source.github.io/portfolio`!
